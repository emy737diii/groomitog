# Сайт груминг-салона: шаблон под любой салон

Сайт с 3D-питомцем, расчётом цены, заявками с фото, личной ссылкой клиента на статус, кабинетом владельца и уведомлениями в Telegram.

**Стек:** Next.js 15 (App Router) + React 19 + TypeScript, PostgreSQL, three.js / React Three Fiber, sharp (обработка фото), Telegram Bot API. Никаких платных сервисов.

## Что умеет

| Часть | Что делает |
|---|---|
| Главная `/` | 3D-питомец (вращение, прыжок по нажатию, фразы), услуги с фото, галерея, расчёт на несколько питомцев, заявка, контакты |
| Заявка | До 3 фото, согласие на ПД (галочка выключена по умолчанию), черновик переживает перезагрузку, защита от дублей и спама. Цена пересчитывается на сервере и фиксируется в заявке |
| Страница клиента `/r/<токен>` | Статус, итоговая цена и время от салона, отмена. Токен случайный, поиска по телефону нет |
| Кабинет `/admin` | Только по логину и паролю, ссылки на сайте нет. Заявки (фильтр, поиск, фото, статус, цена, время, заметка, удаление), Telegram, тарифы, данные салона, смена пароля |
| Telegram | Кнопка «Подключить Telegram» в кабинете → бот → «Старт». Дальше каждая заявка приходит в чат со всеми данными и фото |
| PWA | Манифест, иконки, установка на телефон, экран «Нет подключения» |

## 1. Запуск на своём компьютере

Нужны Node.js 20.6+ и PostgreSQL 14+.

```bash
cp .env.example .env        # заполните DATABASE_URL, SESSION_SECRET, IP_HASH_SALT
npm install
npm run db:migrate          # создаст таблицы и владельца, покажет пароль ОДИН РАЗ
npm run dev                 # http://localhost:3000, кабинет: http://localhost:3000/admin
```

Случайные строки для `.env`: `openssl rand -hex 32`.
Логин по умолчанию `owner`. Пароль можно задать самому в `ADMIN_PASSWORD` до первого `db:migrate`, иначе он сгенерируется.
Забыли пароль: `npm run admin:password -- "НовыйПароль123"` (все старые входы завершатся).

## 2. 3D-модели

1. Скачайте модели с Sketchfab (нужна бесплатная регистрация), формат **glTF / GLB**:
   - Собака: https://sketchfab.com/3d-models/shiba-inu-dog-80419f7e64e24afe97e0931b6aeee612
   - Кошка: https://sketchfab.com/3d-models/cat-70a23788ef984a7a9a1c9a9fe6d5a651
2. Если скачался архив glTF (папка с `scene.gltf`), соберите и сожмите в один файл:
   ```bash
   npx @gltf-transform/cli optimize scene.gltf dog.glb --texture-compress webp --texture-size 1024
   ```
3. Положите файлы в `public/models/dog.glb` и `public/models/cat.glb`. Размер и положение модели подстраиваются автоматически.

> **Важно про лицензии.** Собака — CC BY 4.0, можно на коммерческом сайте с указанием автора (подпись уже есть). Кошка — **CC BY-NC 4.0, только некоммерческое использование**. На сайте настоящего салона её нужно заменить или получить разрешение автора. До этого можно выключить кошку галочкой в кабинете («Салон» → «Показывать 3D-кошку»). При замене модели поправьте подпись в `lib/content.ts` (`MODELS`).

## 3. Telegram-бот

1. В Telegram откройте @BotFather → `/newbot` → получите токен и имя бота (например `ShyorstkaSalonBot`).
2. В `.env` заполните `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` (без @), `TELEGRAM_WEBHOOK_SECRET`, `SITE_URL`.
3. После деплоя на домен с HTTPS выполните один раз: `npm run telegram:webhook`.
4. Владелец заходит в `/admin` → Telegram → «Подключить Telegram» → в боте «Старт». Кабинет сам увидит подключение. Кнопка «Отправить тестовое» проверяет связь.

На локальном компьютере Telegram не достучится до сайта: для проверки нужен публичный адрес (деплой или туннель вроде cloudflared).

## 4. Размещение на хостинге

**Вариант А: VPS (Timeweb, Selectel, REG.RU и т.п.)** — проще всего через Docker:
```bash
cp .env.example .env   # заполните; DATABASE_URL подставится сам из docker-compose
export POSTGRES_PASSWORD=придумайте-пароль
docker compose up -d --build
docker compose logs app | grep Пароль   # пароль владельца, если не задавали свой
```
Перед сайтом поставьте Caddy или nginx с HTTPS (Let's Encrypt), прокси на `localhost:3000`. HTTPS обязателен: без него не заработают Telegram и вход в кабинет.
Пример Caddyfile: `salon.ru { reverse_proxy localhost:3000 }`.

**Вариант Б: облачная платформа с Postgres** (Timeweb Cloud Apps, Railway, Render): создайте базу, укажите переменные из `.env.example`, команда сборки `npm run build`, запуска `node scripts/migrate.mjs && npm start`.
Vercel тоже подойдёт, но фото до 10 МБ там упираются в лимит 4,5 МБ на запрос, поэтому лучше VPS.

**Вариант В: Netlify + бесплатная база Neon** (удобно для теста):
1. Создайте базу на neon.tech, скопируйте строку подключения (с `?sslmode=require`).
2. На своём компьютере впишите её в `.env` как `DATABASE_URL`, выполните `npm install` и `npm run db:migrate` (сохраните пароль владельца).
3. Загрузите проект в GitHub и подключите репозиторий в Netlify (Add new site → Import an existing project). Перетаскивание папки не подойдёт: проекту нужна сборка.
4. Site configuration → Environment variables: добавьте переменные из `.env` (кроме `ADMIN_PASSWORD`). `SITE_URL` — адрес сайта на Netlify.
5. Deploy. После деплоя для Telegram выполните локально `npm run telegram:webhook`.

**Cloudflare Pages не подходит**: там нет полноценного Node.js, а проекту нужны обработка фото (sharp) и прямое подключение к PostgreSQL.

## 5. Под новый салон (чек-лист на 15–30 минут)

- [ ] Новая база и новый `.env` (свои `SESSION_SECRET`, бот, домен)
- [ ] Кабинет → «Салон»: название, телефон, часы, филиалы, заголовок
- [ ] Кабинет → «Тарифы»: цены салона
- [ ] `lib/content.ts`: фото услуг и галереи (локальные фото кладите в `public/photos/` и указывайте `/photos/имя.jpg`), тексты, фразы питомцев
- [ ] `app/globals.css`, блок `:root`: цвета бренда (`--ink` — основной, `--irid` — переливающийся градиент кнопок)
- [ ] `public/icons/`: иконки 192 и 512 px
- [ ] `components/Sections.tsx`: **текст политики обработки ПД конкретного салона** (обязательно до запуска)
- [ ] 3D-модели с подходящей лицензией

## 6. Безопасность

- Пароль хранится как хеш scrypt. Вход: не больше 5 попыток за 15 минут с одного IP.
- Сессия — подписанная httpOnly-cookie на 14 дней. Смена пароля завершает все другие входы.
- Изменяющие запросы кабинета проверяют Origin (защита от CSRF). Все SQL-запросы параметризованы.
- Фото клиентов хранятся в базе и отдаются только владельцу. Перед сохранением они перекодируются: удаляются EXIF и геометки.
- Заявки: не больше 5 за 10 минут с одного IP, повторная отправка не создаёт дубль. IP хранится только в виде хеша.
- Секреты только в `.env` на сервере, в браузер не попадают. `/admin`, `/r/` и `/api/` закрыты от поисковиков.

```
scripts/        миграция, сброс пароля, подключение вебхука
```
